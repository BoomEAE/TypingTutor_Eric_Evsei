# TypingTutor
A typing tutor program by Éric André Evsei

## Overview
TypingTutor is a Java-based desktop application designed to help users learn and practice touch typing—typing quickly and accurately without looking at the keyboard.

## Features
-Interactive typing interface designed to improve speed and accuracy.
-Real-time tracking of correct keystrokes and mistakes.<
-Clean and user-friendly layout
-Prompt generator for authentic prompts
